| Tool | Free Tier | Limits | Best For |

| **HuggingFace Inference** | Free tier | Rate limited | Model experimentation |
| **Mistral API** | Free tier | Limited tokens | Code & reasoning tasks |
| **Cohere** | Free tier | 100 req/min | Embeddings + chat |

### 🔥 Best Free Local Models (via Ollama)
```bash
# Install Ollama then run:
ollama run llama3          # Meta's LLaMA 3 - Great all-rounder
ollama run mistral         # Mistral 7B - Fast & capable
ollama run codellama       # Code-focused tasks
ollama run phi3            # Microsoft Phi-3 - Lightweight
ollama run gemma2          # Google Gemma 2 - Strong reasoning
ollama run deepseek-coder  # Security code analysis
```

## ⚠️ Important Caveats

> 🔒 **Privacy First:** For real security work, always use **local models (Ollama)** — never send sensitive logs, IPs, or incident data to commercial APIs!

> 📜 **Legal:** Only run scanning/pentest tools on systems **you own or have written permission** to test.

> 🌐 **API Rate Limits:** Free tiers have limits — plan your workflows to respect rate limits and cache results.

> ☁️ **Cloud Free Tiers Expire:** Oracle/AWS/GCP free tiers may have time limits — read the fine print.
